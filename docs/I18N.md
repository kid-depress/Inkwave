# Interface languages

Settings → Gameplay → Language / 语言 offers English (`en`, the default) and Simplified Chinese (`zh-CN`).
The existing settings API stores the choice in `inkwave.settings`. Boot applies it before creating the menus and HUD.
Switching language updates existing UI text immediately, including the paused game's HUD; it does not reload or restart a match.
Reset to defaults also restores English. Unsupported saved language values fall back to English.

## Adding copy

English remains the source/fallback. Add translations to `src/ui/locales/zh-CN.js`:

- `ZH_CN` contains complete labels, sentences and accessible descriptions. Case-insensitive lookup also covers uppercase menu labels.
- `ZH_PATTERNS` handles numbers and other interpolated values. Its final argument is the translation function, if a nested label needs translation.
- Leave player names and room codes unchanged when translating surrounding sentences.

`h()` and `frag()` from `src/ui/ui-util.js` bind their text to the current language. For later updates, use
`setText(element, englishCopy)` and `setHTML(element, markup)` from the same module instead of direct `textContent` / `innerHTML` writes.
HTML localization visits text and accessibility attributes; it never rewrites classes, game IDs, SVG geometry or handlers.
`richText()` preserves the original sentence so translated keycap prompts can change word order while retaining their input glyphs.

Player-provided text must opt out: `h('span', { translate: 'no' }, player.name)` or `setText(element, player.name, true)`.
This also protects names that happen to match a label such as `SETTINGS` or `READY`. Plain text is assigned as text, not parsed as HTML.

Bindings retain their English source through weak DOM references. They update on language changes; no DOM mutation observer or per-frame tree scan is used.
Native CJK font fallbacks live in `styles/ui.css`.

## Checks

Run `npm run check` and `npm run test-i18n`. The language test starts its own local server and uses system Chrome
(or a browser named by `CHROME_PATH`) to exercise menus, HUD copy, rich keycaps, player input, keyboard switching and reset.
